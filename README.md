## 🚀 Project Overview

The **Sistem Informasi Kelurahan Kupang Kota V2** is a complete overhaul of the legacy PHP-based village portal into a cutting-edge, high-performance web application built with **Next.js**. 

The goal of this project was to elevate the digital presence of the local government by introducing a highly interactive **Glassmorphism UI**, smooth micro-animations, and AI-driven features, ensuring an engaging and accessible experience for the community.

<br />

## 🎨 UI/UX Design Philosophy: "Glassmorphism & Fluidity"

Instead of relying on standard component libraries (like Bootstrap or Tailwind presets), the entire UI was crafted from scratch using pure **CSS Modules** to achieve a unique, premium aesthetic.

- **Glassmorphism**: Extensive use of backdrop blurs and semi-transparent layers to create depth.
- **Fluid Micro-Animations**: Powered by **Framer Motion**, elements feature spring-physics hover states and smooth scroll-triggered entrances.
- **Dynamic Color Themes**: Custom color palettes tailored to specific sections (e.g., Emerald Green for Tim KKN, Heritage Gold for the History section).

## ✨ Key Technical Highlights

### 🗺️ Interactive UMKM & Village Map
An interactive GIS (Geographic Information System) dashboard for local businesses (UMKM).
- Built with **React-Leaflet** and natively optimized hooks.
- Features: Real-time "Open/Closed" status, category filtering, skeleton loaders for seamless data fetching, and multiple map layers.

### 🤖 Split-Screen AI Chatbot with Voice Assistant
A highly accessible AI chatbot designed to help citizens quickly find administrative information.
- Split-screen UI allowing users to browse the site while simultaneously chatting with the AI.
- Integrated **Voice Assistant** capabilities for hands-free queries.

### 🏛️ Dynamic Profile Ecosystem
An intricate set of profile pages.
- Custom masonry and pyramid grid structures for the Organization Chart, stepping away from standard linear layouts.
- Highly optimized images and assets via Next/Image.

| **Maps** | Leaflet.js & React-Leaflet |
| **Icons** | Lucide React |

### 💡 Why CSS Modules over Utility-First (e.g., Tailwind)?
To achieve the highly specific, organic, and bouncy aesthetics requested by the client, strict CSS Modules were utilized. This allowed for granular control over complex `nth-child` staggering, pseudo-element blobs (`::before`, `::after`), and custom grid positions without cluttering the TSX components with excessively long utility classes.
